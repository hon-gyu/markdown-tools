# Welcome to the vault

This whole site is generated from the `vault/` directory. Every markdown file
becomes a page at a URL that mirrors its path — the folder structure *is* the
navigation you see on the left.

Wikilinks resolve by **filename**, not title: [[async]] finds `rust/async.md`,
and you can path-qualify with [[rust/index|the Rust hub]] or use an alias. A link
to a note that doesn't exist renders as [[a missing note]] so it stays visible.
